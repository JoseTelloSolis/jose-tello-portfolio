## Requisitos

- Node.js 22.22 o superior
- npm

## Instalación local

```bash
npm install
npm run dev
```

El proyecto estará disponible en:

- http://localhost:4321

## Build y despliegue

```bash
npm run build
npm run preview
```

El comando `npm run build` genera una versión estática del sitio en `dist/`, lista para ser desplegada en plataformas modernas como Vercel.

## Despliegue

Este portfolio está preparado para publicarse de forma simple y profesional:

1. Conecta el repositorio a Vercel.
2. Usa la configuración incluida en `vercel.json`.
3. Vercel detecta la app Astro y ejecuta el build correcto.
4. Cada push a la rama principal publica una nueva versión.

### Dominio personalizado

```bash
SITE_URL=https://tu-dominio.com
```

Luego se configura el dominio desde la sección de ajustes de Vercel.
